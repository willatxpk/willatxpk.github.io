💰 Kerdos setup guide

Kerdos is a personal finance app that runs on your own Windows PC. Your data stays on your computer and is never uploaded anywhere.

⬇ Download Kerdos

Steps
  1. Install and start it
  2. Connect your accounts
  3. Use it from your phone
  4. Add a local AI model (optional)
  5. Phone and email alerts (optional)
  6. Update to a new version

1. Install and start it

  1. Install Python 3.12 from python.org. In the installer, tick "Add python.exe to PATH". Kerdos uses only Python's built-in parts, so there's nothing else to install.
  2. Download kerdos.zip above, right-click it and choose Extract All. Put the folder somewhere it can stay, such as Documents\Kerdos.
  3. Open the folder and double-click run.bat. A console window opens, and your browser opens http://localhost:8765.
  4. Create a password the first time it asks. You'll sign in with it from then on, and it locks itself after 30 minutes of inactivity.

Make it start automatically (recommended)

Right-click install_autostart.ps1 and choose Run with PowerShell. Kerdos then runs quietly in the background whenever you sign in to Windows, with no window. Open it any time at http://localhost:8765 or with the Open Kerdos shortcut in the folder. To turn this off, run uninstall_autostart.ps1.

Windows warning? If Windows says it can't run the script, open PowerShell in the folder and run powershell -ExecutionPolicy Bypass -File .\install_autostart.ps1. This affects only that one run.

Encrypt your data

Go to Accounts → Encrypt my data. You'll get a one-time recovery code. Save it in a password manager or on paper, because without it a forgotten password can't be recovered.

2. Connect your accounts

Pick one of the two options below. If you just want to look around first, use the demo data on the welcome screen.

Option A: automatic sync through Plaid

Plaid is the service most budgeting apps use to connect to banks. You sign in to your bank in Plaid's own window, so Kerdos never sees your bank password.

  1. Make a free account at dashboard.plaid.com/signup.
  2. In the Kerdos folder, copy config.example.json and rename the copy to config.json.
  3. In the Plaid dashboard, open Developers → Keys. Paste your client_id and secret into config.json.
  4. Leave "env": "sandbox" at first. Sandbox uses fake test banks, which you sign in to with user_good / pass_good, so you can check it works.
  5. For your real accounts, request Production access in the Plaid dashboard. Personal projects can usually get a small number of free live connections. Then change "env" to "production" and paste in the production secret.
  6. Restart Kerdos and click Accounts → Connect a bank.

Kerdos syncs every 6 hours while it's running, and whenever you click Sync now. When it starts, it encrypts the secret in config.json so only your Windows account can read it.

Keep config.json private. It holds your Plaid secret. Never share it or upload it anywhere.

Option B: import CSV files (no Plaid)

On each bank's website, download your transactions as a CSV file. Then use Accounts → Import a CSV. Importing a file that overlaps an earlier one won't create duplicates.

3. Use it from your phone

This uses Tailscale, a free private network between your own devices. Your phone reaches your PC from anywhere, and nothing is opened up to the public internet.

  1. On your PC: install Tailscale from tailscale.com/download and sign in. A Google, Microsoft or Apple account is easiest.
  2. On your phone: install the Tailscale app (App Store or Google Play), sign in with the same account, and allow the VPN when it asks. Leave it switched on.
  3. On your PC, open PowerShell and run: 
    tailscale serve --bg 8765
    It prints your PC's private address, which looks like https://your-pc.tail1234.ts.net. The first time, it may print a link to turn on HTTPS. Open the link, click Enable, then run the command again.
  4. In Kerdos on your PC: go to Accounts → Phone access → Allow my Tailscale address. The address is filled in for you. Click OK.
  5. On your phone, open the browser (Safari on iPhone), go to that https://…ts.net address, and sign in with your Kerdos password.
  6. Tap Share → Add to Home Screen. Kerdos now opens like an app, with its own icon.
  • Your PC has to be on and awake. To stop it sleeping while plugged in: Settings → System → Power → Sleep → Never (when plugged in).
  • Only devices signed in to your Tailscale account can reach it. Never use tailscale funnel, which would make it public.
  • To turn phone access off, run tailscale serve reset and remove the address under Accounts → Phone access.

4. Add a local AI model (optional)

Kerdos sorts most transactions on its own. For the few it isn't sure about, an AI model running on your own computer can suggest a category. Nothing is sent to the internet, and suggestions only appear on the Sort page. They're never applied without you.

  1. Install Ollama from ollama.com/download and start it. It sits in the system tray.
  2. Open PowerShell and download a small model (about 2 GB): 
    ollama pull qwen2.5:3b
    Other models work too, such as llama3.2:3b or gemma3:4b. Bigger models sort better but run slower.
  3. In Kerdos, go to Settings → Sorting help from a local AI model. Tick "Ask the local model about transactions the app can't call" and pick your model.

Your PC may slow down for a few seconds while the model thinks. Kerdos unloads the model from memory as soon as it's done.

5. Phone and email alerts (optional)

Kerdos can warn you before bills are charged, when a price changes, or when an account is running low.

  • Phone: install the free ntfy app and subscribe to a long, random topic name such as kd-8e2kq93nd0x. Anyone who knows the name can read it, so make it hard to guess. In config.json, set "ntfy_url": "https://ntfy.sh/your-topic-name".
  • Email: in config.json, set notify.email.enabled to true and fill in your mail server details. For Gmail, use an App Password, not your normal password.

Restart Kerdos, then click Bills & Alerts → Send test alert.

6. Update to a new version

  1. Close Kerdos. Run uninstall_autostart.ps1, or end pythonw.exe in Task Manager.
  2. Download the new kerdos.zip and extract it over your existing folder, replacing the files. Your data folder and config.json aren't in the download, so they're left alone.
  3. Start it again with install_autostart.ps1 or run.bat.

Forgot your password?

Close Kerdos first (see above). Then open PowerShell in the Kerdos folder:

  • With encryption on: run py -3.12 main.py --recover and enter your recovery code.
  • Without encryption: run py -3.12 main.py --reset-password. Your data is untouched.
